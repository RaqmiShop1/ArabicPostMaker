# ArabicPostMaker
برنامج Windows لأصحاب المتاجر والأسر المنتجة: صمّم منشورات بيع عربية أنيقة لإنستقرام وواتساب خلال ثوانٍ — 5 قوالب جاهزة (خصم، وصل حديثًا، منتج مميز، تهنئة، إعلان) و15 لونًا ومقاسا المنشور والستوري، بشعار متجرك وحساباتك على كل تصميم. والأقوى: الصق قائمة منتجاتك من Excel فيولّد منشورًا لكل منتج دفعة واحدة. كل شيء على جهازك دون اشتراكات.
